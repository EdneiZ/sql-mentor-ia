# SQL Mentor IA

## Descrição

O SQL Mentor IA é um assistente virtual desenvolvido para auxiliar estudantes e profissionais iniciantes na aprendizagem de SQL.

O assistente utiliza uma base de conhecimento estruturada para responder dúvidas sobre comandos e conceitos fundamentais de banco de dados.

## Objetivo

Facilitar o aprendizado de SQL através de respostas rápidas e objetivas.

## Público-alvo

- Estudantes de tecnologia
- Analistas de dados iniciantes
- Desenvolvedores iniciantes

## Funcionalidades

- Explicação de comandos SQL
- Consulta à base de conhecimento
- Respostas automáticas
- Encerramento da conversa pelo usuário

## Tecnologias Utilizadas

- Python
- JSON
- Git
- GitHub
